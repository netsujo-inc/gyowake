# 行わけのロードマップ

原文を保って日本語Webの読みづらい改行・段落を改善し、その結果を確認できる状態を目指します。

| 段階 | 作業 | 受入条件 |
| --- | --- | --- |
| 1 公開版の整備 | 日本語README、導入・更新・旧版移行、名称一次調査、配布物の検証 | 初見の開発者が手順・限界を把握し、コピーとホスト読込を分けて確認できる |
| 2 実サイトの事例 | 受入済みフッター修正の原因・最小修正・検証環境・公開状態・残課題を整理 | 実ブラウザ証拠とソースに結び付いた限定事例を公開 |
| 3 外部利用 | 開発者3人による導入・実ページ改善、失敗・誤検出・時間を観測 | 作者の説明なしで導入→監査→修正→再検証を完了した証拠 |
| 4 v1.0 | 実利用で再現した問題を修正し、範囲・互換性・受入条件を確定 | 段階3の成果、必要な回帰と独立レビューが成立 |
| 5 事業への接続 | SIGNAL・Web制作・研修で利用 | 品質・作業時間・商談などへの寄与を実測 |

段階1・2の資料を整備しています。ソース受入と公開反映は、対応するPRのmergeと最終公開URLの確認結果で判定します。外部3人の実利用、v1.0の安定性、事業効果は未検証です。外部連絡・参加依頼は宛先と内容が承認された範囲で行います。

評価指標は導入成功率・誤検出・修正所要時間・再発率。対象数と確認条件を併記します。公開・ダウンロード数と、実際の改善成果を分けて追います。

npm配布・専用管理画面・単独の有料サービスは、外部利用で必要性が確認できた段階で判断します。
