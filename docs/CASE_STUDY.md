# 実サイト事例：文字拡大時のフッター折り返し

NetsujoのWebサイトで、共有フッターの4リンクを狭い幅・文字拡大時にも読めるようにした事例です。旧名称Kaigyoで進めた既存作業の受入済み限定成果を整理しています。

対象：[netsujo.jp/services](https://netsujo.jp/services)などの日本語共通フッター。変更：[SITE PR #670](https://github.com/suirindo/netsujo-site/pull/670)。サイト全体の残課題は[SITE #563](https://github.com/suirindo/netsujo-site/issues/563)で管理しています。

## 問題と最小修正

折り返さず4リンクを並べるflexコンテナが、狭い幅と拡大文字の組合せではみ出しの原因になりました。文字・URL・文字サイズを保持し、折り返しと縦の間隔を追加しました。

```diff
- mt-8 flex items-center gap-5
+ mt-8 flex flex-wrap items-center gap-x-5 gap-y-3
```

語句保護を増やす前に、原因のあるコンテナの幅と並べ方を直した例です。

## 限界と応用

root font 32pxはCSSによる文字拡大ストレスです。ブラウザ本体の200%ズームとは区別します。全ページの意味的な改行・段落、別要素の切れ・はみ出し、Safari・Firefoxは本事例の範囲外です。

独立配布版を外部開発者が導入して同じ成果を得る実験は、今後の外部利用検証で扱います。事業効果・作業時間短縮・利用者による読みやすさの評価は未測定です。

他サイトでは、幅とフォントを固定→原因要素を特定→原文を保って最小修正→対象とページ全体を別々に測定→コード・レビュー・公開画面へ証拠を結び付ける、という順で応用できます。
